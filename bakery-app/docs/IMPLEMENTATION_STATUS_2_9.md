# حالة تنفيذ استكمال 2.9 Enterprise

آخر تحديث: 2026-11-06

## ما أُضيف في فرع التطوير
- رفع إصدار قاعدة بيانات دفتر المخبز من 4 إلى 5 مع ترحيل إضافي لا يحذف جدول records ولا يعيد إنشاء قاعدة 2.8.0.
- إضافة EnterpriseSchema لإنشاء جداول تأسيسية للبلدان والعملات وأسعار الصرف والفروع والمستخدمين والأدوار والصلاحيات والموردين وفواتير الشراء والدفعات والموظفين ومسيرات الرواتب والأصول والإهلاك والضرائب والفترات المالية ودليل الحسابات ودفتر الأستاذ وصندوق المزامنة.
- إضافة EnterpriseMath لتحويل العملات بمعدلات كسرية دقيقة، وحساب صافي الرواتب، والإهلاك بالقسط الثابت مع منع تجاوز القيمة المتبقية.
- إضافة PortableBackupCrypto لتشفير النسخة بكلمة مرور باستخدام AES-GCM ومفتاح مشتق عبر PBKDF2، مع كشف سلامة الملف ودعم استيراد ملفات JSON القديمة.
- تحديث شاشة النسخ الاحتياطي لتصدير ملف .mizanbak مشفر، واستيراده بكلمة المرور، مع محاولة تراجع تعويضي إذا فشل استيراد أحد الدفترين.
- إزالة كميات وأسعار المخزون الافتراضية التي قد توهم المستخدم بوجود أرصدة حقيقية؛ تبدأ الأصناف بأرصدة صفرية.
- إضافة اختبارات وحدات واختبارات Android instrumentation، وإضافة فحوص مصدرية إلى workflow.

## تحقق محلي محدود
- اختُبرت دوال الحساب الجديدة بعشرة تأكيدات Java مستقلة.
- اختُبر تشفير النسخة وفكها وكلمة المرور الخاطئة وتعديل الملف على Java محلياً.
- هذه الاختبارات المستقلة لا تحل محل Gradle أو Android instrumentation أو محاكي API 23/35.

## ما لم يكتمل بعد — لا يجوز وصفه بأنه ميزة جاهزة
1. واجهات إدارة الموردين وفواتير الشراء والدفعات ومردودات الشراء.
2. ترحيل فاتورة الشراء إلى مخزون المخبز الفعلي وإلى دفتر الأستاذ في معاملة واحدة.
3. واجهات الموظفين ومسيرات الرواتب والسلف والخصومات والدفع وربطها بقيود محاسبية.
4. واجهات الأصول وعمليات الاقتناء والاستبعاد والصيانة وجدولة الإهلاك وترحيله.
5. إنشاء حسابات المستخدمين الفعلية، وتطبيق الصلاحيات على كل عملية، وربط المستخدم بالفروع.
6. خدمات ترحيل قيود دفتر الأستاذ التي تضمن توازن مجموع المدين والدائن بعملة الأساس، مع فروق العملة وسعر المعاملة التاريخي.
7. ملفات ضرائب مفعلة ومراجعة لكل بلد، وليست مجرد جداول إعداد.
8. خدمة مزامنة خادمية فعلية ومعالجة التعارضات ومنع التكرار واختبارات تعدد الأجهزة.
9. تجربة مجانية مرتبطة بالخادم والجهاز مع سياسة تحقق ومهلة offline؛ لا تزال آلية التجربة المحلية القديمة قائمة.
10. إدخال جداول المؤسسة الجديدة في صيغة النسخ الاحتياطي واستعادتها بعد إكمال وحداتها، مع ترحيل نسخ المخطط.
11. اختبار تحديث 2.8.0 فوق تثبيت فعلي مع إثبات الأرصدة، واختبار الاستعادة الكاملة على جهاز.
12. تشغيل GitHub Actions ونجاح Gradle وinstrumentation على API 23 و35.

## سياسة الإصدار
- لا يُرفع هذا الفرع إلى إصدار تجاري الآن.
- لا يتغير applicationId أو مفتاح التوقيع أو الأسعار أو طريقة اعتماد الدفع.
- يجب زيادة versionCode وversionName عند أول APK قابل للتثبيت فوق 2.8.0، مع تحديث فحوص إصدار Worker ومُصدر التراخيص وسير عمل النشر معاً.
- لا تدمج التغييرات في فرع إصدار 2.8.0؛ يجب إعداد فرع إصدار جديد بعد اجتياز جميع بوابات القبول.
