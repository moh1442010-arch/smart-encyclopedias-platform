# استكمال المحاسب الميزان للمخابز — مواصفة 2.9 Enterprise

هذه مواصفة تنفيذ واختبار وليست ادعاءً بأن الميزات أدناه أصبحت منفذة.

## مبادئ إلزامية
- الحفاظ على applicationId ومفتاح التوقيع وأسماء قواعد بيانات 2.8.0.
- ترحيل متدرج قابل لإعادة التشغيل، مع نسخة قبل الترحيل ومقارنة أرصدة وعدد سجلات.
- لا عملية مالية جزئية: تحديث المخزون والدفتر والحسابات داخل معاملة واحدة.
- تخزين الأموال كأعداد صحيحة بوحدة العملة الصغرى، لا float/double.
- استمرار تسجيل العمليات اليومية دون إنترنت؛ لا حذف بيانات عند انتهاء الترخيص.
- لا مزامنة أو تعدد مستخدمين قبل معالجة تكرار العمليات وتعارض القيود.

## P0 — سلامة الحسابات والبيانات
1. تصحيح مفهوم الربح: فصل المبيعات عن التحصيل، وإظهار هامش ما بعد المواد، ومجمل الربح بعد تكلفة المبيعات والهالك، وصافي التشغيل بعد الأجور والمصروفات. لا احتساب للهالك مرتين.
2. توحيد الحسابات بين ملخص المخبز والتقارير والمصنع، وإضافة فترات من/إلى وتسويات قابلة للتتبع.
3. إزالة كميات وأرصدة المخزون الافتراضية من النسخة الإنتاجية؛ بيانات العرض اختيارية ومعزولة.
4. إنشاء حزمة نسخ احتياطي واحدة للمخبز والمصنع والإعدادات، مشفرة ومتحققاً من سلامتها.
5. إنشاء snapshot قبل الاستعادة، والتحقق الكامل قبل الاستبدال، وتنفيذ الاستعادة ذرياً أو التراجع عن كل التغييرات. توضيح خيار الدمج أو الاستبدال بدقة.
6. اختبار تحديث 2.8.0 على قواعد فعلية تجريبية مع إثبات عدم فقد صف أو رصيد.

## P0 — التجربة والترخيص
- حالة تجربة موقعة ومخزنة خادمياً ومربوطة بهوية منشأة/تثبيت، لا SharedPreferences فقط.
- Android ID إشارة ربط مساعدة لا هوية عتادية مضمونة؛ دعم نقل الجهاز وإعادة التفعيل بموافقة الإدارة.
- سياسة offline معلنة: مهلة سماح بعد آخر تحقق ناجح، ثم وضع قراءة وتصدير فقط؛ لا حذف ولا حجب للدفاتر.
- اختبارات مسح البيانات وإعادة التثبيت وتغيير الساعة والجهاز وانقطاع الإنترنت وتكرار طلب التفعيل.
- مفاتيح التوقيع الخاصة في الخادم فقط.

## P1 — الموردون والمشتريات
- ملفات الموردين، فواتير شراء نقدية وآجلة، بنود ومردودات، دفعات جزئية، كشف حساب وأعمار ديون.
- كل فاتورة تحدث المخزون والتكلفة وحساب المورد والقيد المحاسبي في معاملة واحدة.
- منع تكرار الفواتير والتحقق من الكميات والأسعار.

## P1 — الموظفون والرواتب
- ملف موظف، أجر أساسي، استحقاقات واستقطاعات، سلف، إضافي، مسير رواتب للفترة، دفع جزئي وكشف راتب.
- قيود الاستحقاق والسداد لا تتكرر عند إعادة المحاولة، مع تقييد الوصول للبيانات.

## P1 — الأصول الثابتة
- سجل الأصل وتكلفة الاقتناء والعمر والقيمة المتبقية وطريقة الإهلاك والموقع والحالة.
- إهلاك دوري بقيد قابل للعكس، وصيانة وتحسينات واستبعاد/بيع الأصل.
- عدم تسجيل الأصل كمصروف تشغيلي إذا انطبقت سياسة الرسملة.

## P2 — الصلاحيات والفروع
- أدوار المالك والمدير والمحاسب وأمين المخزن والكاشير والمراجع بصلاحيات دقيقة.
- فصل بيانات المنشآت والفروع، وترقيم مستندات مستقل، وتحويلات مخزون ونقد بقيود مقابلة.
- سجل تدقيق لا يمكن تعديله من واجهة التطبيق.

## P2 — المزامنة والعمل متعدد الأجهزة
- معرفات UUID، صندوق إرسال/استقبال، مفاتيح idempotency لمنع التكرار، معالجة حذف وتعارضات موثقة.
- لا تستخدم قاعدة «آخر تعديل يفوز» في القيود المالية؛ التعارض المالي يحتاج تسوية ومراجعة.
- لا تُفعّل المزامنة قبل اختبارات انقطاع الشبكة وتكرار الطلبات وتعارض الأجهزة.

## P3 — تعدد العملات والبلدان
- عملة أساس وعملات معاملات وفق ISO 4217، أسعار صرف مؤرخة ومصدرها، تثبيت السعر التاريخي، وفروق عملة عند السداد والإقفال.
- إعدادات البلد والضرائب والسنة المالية والمنطقة الزمنية والتاريخ ووحدات القياس واللغة.
- حزم ضريبية منفصلة لكل بلد؛ لا تعميم نسبة ضريبية واحدة.

## بوابات القبول قبل النشر
- صفر فقد بيانات عند التحديث من 2.8.0.
- كل القيود متوازنة والتقارير تطابق دفتر الأستاذ للفترة نفسها.
- الاستعادة تعيد المخبز والمصنع معاً أو لا تغيّر أياً منهما.
- سيناريوهات الشراء الآجل والسداد والمرتجع والرواتب والإهلاك مجربة.
- العمل اليومي offline مستمر، وانتهاء المهلة لا يحجب الدفاتر.
- اختبارات أجهزة Android منخفضة الذاكرة وإصدارات API المدعومة.
- لا إصدار تجاري قبل نجاح اختبارات P0 والتوقيع بنفس مفتاح الإصدار السابق.

## ترتيب الإصدارات المقترح
- 2.8.1: الربحية والتقارير والنسخ الاحتياطي الذري المشفر والمخزون الافتراضي واختبارات الترحيل.
- 2.8.2: سياسة التجربة والترخيص offline.
- 2.9.0: الموردون والمشتريات والرواتب والأصول والدفتر العام.
- 2.9.5: الصلاحيات والفروع وسجل التدقيق.
- 3.0.0: العملات والضرائب والمزامنة بعد اجتياز اختبارات التعارض.
