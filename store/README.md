- الاستضافة المجانية المقترحة: GitHub Pages.
- العنوان المقترح بعد النشر: https://moh1442010-arch.github.io/smart-encyclopedias-platform/store/
- لا يتم شراء نطاق مستقل في المرحلة الأولى.
- لا توجد روابط تنزيل نهائية في الصفحة حتى اعتماد APK أندرويد الموقّع وملف Windows المختبر.

## ما تحتويه الصفحة
- عرض أولي لباقات Basic وPro وBusiness وEnterprise.
- جدول أسعار السودان والسعودية بوصفها أسعارًا مؤقتة للمراجعة.
- طلب الاستفسار عبر WhatsApp.
- مركز تنزيل معطّل عمدًا إلى أن تتوفر ملفات معتمدة وبصمات SHA-256.
- تنبيه واضح بأن الصفحة ليست بوابة دفع آلية، وأن إرسال الطلب لا يفعّل الترخيص.

## النشر
هذه الصفحة موجودة في فرع التطوير feature/al-mizan-free-storefront ولا تُعد منشورة بمجرد إضافتها إلى GitHub. بعد مراجعة طلب الدمج، يجب التأكد من إعدادات GitHub Pages أو مسار النشر الحالي قبل الدمج. لا تغيّر إعدادات النشر الحالية ولا تدمج تغييرات متجر غير مراجعة في الفرع الرئيسي.

## شروط قبل البيع
1. اعتماد الأسعار النهائية وشروط الترخيص والاسترداد والدعم.
2. بناء APK موقّع واختباره على جهاز فعلي.
3. بناء واختبار نسخة Windows قبل إضافة رابطها.
4. نشر الملفات المعتمدة في مكان تنزيل مضبوط وتسجيل SHA-256 ورقم الإصدار.
5. اختبار الترخيص بعد التحقق من الدفع من جهة الخادم؛ لا تعتمد على زر الواجهة أو رسالة WhatsApp وحدهما لتفعيل الترخيص.
6. اختبار الصفحة المنشورة على الهاتف والكمبيوتر، والتحقق من الروابط وHTTPS.
