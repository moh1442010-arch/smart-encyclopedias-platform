# حساب التربال — الترخيص والتفعيل

## الأسعار الحالية
- شهري: 70,000 جنيه سوداني لمدة 30 يوماً.
- سنوي: 650,000 جنيه سوداني لمدة 365 يوماً.
- دائم: 1,300,000 جنيه سوداني، مرتبط بالجهاز الذي يصدر له الترخيص.
- الأسعار محفوظة في إعدادات D1 وتُقرأ عبر `/api/config`، ويمكن تعديلها من لوحة `/admin` دون إصدار APK جديد.
- التجربة المجانية: 15 يوماً من أول تسجيل للجهاز على الخادم.

## التدفق
1. أول تشغيل يتصل التطبيق بخادم الترخيص ويسجل معرّف Android للجهاز.
2. يبدأ الخادم مدة التجربة مرة واحدة لهذا المعرّف.
3. بعد انتهاء التجربة، يعرض التطبيق الخطط وبيانات التحويل ويطلب اسم العميل ورقم التواصل ومرجع التحويل.
4. ينشئ الخادم طلباً بحالة pending فقط.
5. يراجع المسؤول التحويل في الحساب البنكي فعلياً من لوحة الإدارة.
6. يعتمد المسؤول الطلب، ويصدر الخادم رمزاً رقمياً موقّعاً مرتبطاً بالجهاز.
7. يجلب التطبيق الترخيص ويثبت صحته بالمفتاح العام المضمّن في التطبيق.

لا يُعد مرجع التحويل دليلاً على وصول المبلغ. لا تعتمد أي طلب قبل التحقق الفعلي.

## إعدادات النشر المطلوبة
ملفات هذا المنتج منفصلة عن Worker المخابز، لكن جداول D1 تستخدم بادئة tirbal_ داخل قاعدة D1 الحالية حتى لا تتداخل سجلات المنتجات.

أضف أسرار GitHub التالية قبل تشغيل سير عمل النشر:
- CLOUDFLARE_API_TOKEN: رمز Cloudflare بصلاحية Worker وD1.
- TIRBAL_LICENSE_PRIVATE_KEY_B64: محتوى ملف المفتاح الخاص بصيغة PKCS#8 Base64.
- TIRBAL_ADMIN_PASSWORD: كلمة مرور إدارة عشوائية لا تقل عن 32 حرفاً.
- TIRBAL_PAYMENT_BANK_NAME: اسم البنك أو وسيلة التحويل.
- TIRBAL_PAYMENT_ACCOUNT_NAME: اسم صاحب الحساب.
- TIRBAL_PAYMENT_ACCOUNT_NUMBER: رقم الحساب الذي سيظهر للعملاء.
- TIRBAL_PAYMENT_WHATSAPP: رقم واتساب الدعم بصيغة دولية من دون علامة +.

لا تضع المفتاح الخاص أو بيانات الحساب البنكي في ملفات المستودع. بيانات الدفع تُمرر إلى Worker كأسرار، ثم يعرضها endpoint الإعدادات العامة للعملاء.

## حدود الأمان الحالية
- التطبيق لا ينشئ DbHelper ولا يفتح قاعدة SQLite قبل اجتياز فحص الترخيص.
- تنتهي واجهة التطبيق عند انتهاء صلاحية الرمز، ويغلق مساعد قاعدة البيانات.
- التحقق من الرمز يعتمد توقيع RSA وربط الجهاز ووقت انتهاء الترخيص.
- مرشح التطبيق 1.3.0 يتضمن SQLCipher 4.20.0 ومفتاح قاعدة بيانات محمياً بواسطة Android Keystore، مع ترحيل يحافظ على نسخة SQLite القديمة حتى اكتمال النسخ. لم يُثبت نجاح هذا الترحيل على جهاز فعلي بعد؛ يلزم اختبار ترقية يحصي المشاريع والتكاليف والمبيعات والرزنامة قبل الاعتماد.
- لا تعتبر الخدمة منشورة حتى ينجح سير النشر وفحص توقيع المفتاح الحي. لا يُنصح بتوزيع APK 1.3.0 قبل نشر Worker وإضافة الأسرار واختبار جهاز حقيقي.
