# الخطة التجارية المعتمدة — المحاسب الذكي

آخر تحديث: 2026-10-13

## حالة التنفيذ
- أُضيفت شاشة داخل التطبيق باسم «الباقات والأسعار» من لوحة التحكم.
- الشاشة تشرح الترخيص الدائم والاشتراك الشهري والسنوي، وتعرض مستويات Basic وPro وBusiness وEnterprise.
- الأسعار المعروضة موسومة بأنها أسعار اختبار أولية وليست أسعار إطلاق معتمدة.
- الشراء والتفعيل والتجديد غير متاحين من الشاشة؛ لا يوجد بعد نظام ترخيص خلفي تجاري متكامل.
- لم تُنشأ تقييمات عملاء افتراضية. التقييمات الحقيقية تحتاج خدمة خلفية/واجهة مراجعات مع آلية للتحقق من الترخيص أو الشراء.

## نموذج المنتج
1. **Basic**: المبيعات والمشتريات والمخزون والعملاء والموردون والتقارير الأساسية بعد اختبار الوظائف.
2. **Pro**: وظائف Basic مع تقارير ووظائف محاسبية موسعة بعد اعتماد الاختبارات.
3. **Business**: احتياجات أوسع للمستخدمين والصلاحيات والفروع، فقط بعد اكتمال التنفيذ الفعلي.
4. **Enterprise**: عرض مخصص بحسب الفروع والمستخدمين والتكاملات والدعم.

كل مستوى له ثلاثة خيارات تجارية:
- **ترخيص دائم**: حق استخدام النسخة المحددة، ولا يشمل مزايا جديدة مستقبلية أو خدمات مستمرة إلا إذا نص العقد على ذلك. يجب إعلان سياسة إصلاحات الأمان والتوافق.
- **شهري**: المزايا والتحديثات والدعم المشمولة طوال فترة الاشتراك.
- **سنوي**: المزايا المشمولة نفسها لمدة سنة، مع خصم سنوي معلن مقارنة بالدفع الشهري.

## تجربة مجانية
تجربة 7 أيام هي هدف المنتج المعتمد. المؤقت المحلي الحالي لا يُعد نظامًا تجاريًا آمنًا، إذ يمكن التلاعب به بإعادة ضبط بيانات التطبيق. لا يُعلن اكتمال التجربة التجارية قبل تنفيذ خدمة الترخيص واختبار انتهاء التجربة، إعادة تثبيت التطبيق، تغيير الجهاز، انقطاع الاتصال، والتجديد.

عند انتهاء الاشتراك، لا تُحذف بيانات العميل ولا يُمنع من تصديرها.

## تقييمات العملاء الحقيقية
- لا تُعرض تقييمات تجريبية على أنها آراء حقيقية.
- التقييم الموثّق لا يُمنح إلا بعد التحقق من شراء أو ترخيص حقيقي.
- يجب إتاحة الإبلاغ عن الإساءة وعدم حذف النقد المشروع لمجرد كونه سلبيًا.
- يلزم تخزين آمن، ومكافحة التكرار والإغراق، وسياسة خصوصية، وآلية إدارة ومراجعة.

## متطلبات ما قبل البيع
1. خدمة ترخيص خلفية مع سجلات للتراخيص وخطط المنتج وتواريخ البداية والانتهاء.
2. واجهة API للتحقق والتجديد والإلغاء ونقل الترخيص، مع مهلة انقطاع اتصال محدودة ومدروسة.
3. تكامل دفع مناسب لكل سوق، مع إيصالات وسياسة استرداد وضرائب.
4. اختبار أن انتهاء الاشتراك لا يحذف البيانات أو يمنع تصديرها.
5. اختبار محاسبي شامل وأمن قاعدة البيانات والنسخ الاحتياطية قبل إطلاق الباقات المدفوعة.
6. عدم تسويق تعدد الفروع أو المزامنة أو النسخ السحابي أو دعم المؤسسات كميزات جاهزة قبل تنفيذها واختبارها.
