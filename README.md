## QA

مصدر الأسعار والخصومات هو `assets/config.js`.

تم اعتماد نسخة PDF سليمة من 250 صفحة بعد فحص عدد الصفحات وإمكانية فتحها ورسمها.

تم تصحيح صفحة الفهرس في نسخة الاعتماد النهائية لإزالة رموز الخطأ واستعادة عناوين الأبواب كاملة.

## التشغيل

الموقع يعمل عبر Cloudflare Workers مع D1 لتسجيل الطلبات.

الوكيل السحابي يستخدم `GEMINI_API_KEY` كسر داخل بيئة Worker ولا يوضع المفتاح داخل ملفات الواجهة.

حالة الطلب تبدأ `pending` ولا تعتبر عملية الدفع مكتملة إلا بعد التحقق اليدوي.

الموقع المنشور يجب اختباره بعد كل نشر على الهاتف والكمبيوتر.
