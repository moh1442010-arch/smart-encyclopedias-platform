# منصة الموسوعات الذكية

## النسخة التجارية الحالية

- الموسوعة الشاملة في الذكاء الاصطناعي باللغة العربية
- النسخة الكاملة: 250 صفحة
- المعاينة: 20 صفحة
- السعر المحلي: 130,000 جنيه سوداني
- أول 100 نسخة: خصم 10%، السعر 117,000 جنيه
- الطلاب: خصم ثابت 10%، السعر 117,000 جنيه
- الدولار: 19 USD، وسعر العرض 16 USD
- الدفع المحلي: بنكك — بنك الخرطوم
- الدفع الدولي: IBAN بنك الخرطوم
- مع كل نسخة كاملة: وكيل ذكي للمساعدة في الشرح والفهم والإجابة عن الأسئلة

## QA

مصدر الأسعار والخصومات هو `assets/config.js`، وتستخدم الواجهة والمساعد هذه القيم بدل نسخ أسعار ثابتة داخل النصوص.

الموقع منشور عبر GitHub Pages. بعد كل تحديث يجب انتظار نشر GitHub Pages ثم اختبار النسخة المنشورة على الهاتف والكمبيوتر.
