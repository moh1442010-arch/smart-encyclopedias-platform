# منصة الموسوعات الذكية

واجهة عربية RTL لمعاينة موسوعة الذكاء الاصطناعي مع 20 صفحة مجانية، منطقة عرض للنسخة الكاملة، ومساعد محادثة للإجابة عن أسئلة العميل حول المحتوى والسعر والشراء.

## البنية
- `index.html` الواجهة الرئيسية.
- `assets/styles.css` التصميم.
- `assets/app.js` المعاينة والمساعد التفاعلي.
- `assets/config.js` إعدادات المنتج والسعر والعرض.
- `assets/assets/preview/` صور المعاينة عند توفرها.
- `الموسوعة_الشاملة_20_صفحة_للمعاينة.pdf` ملف المعاينة البديل المستخدم عند غياب صور الصفحات.

## تحديث السعر والعرض
عدّل القيم في `assets/config.js`:
- `price`
- `currency`
- `oldPrice`
- `offerTitle`
- `offerText`
- `purchaseUrl`
- `previewPdf`

## الاختبار والنشر
المشروع واجهة HTML/CSS/JavaScript ثابتة ولا يحتوي على `package.json` أو اعتماديات npm.

يتم فحص JavaScript تلقائيًا عبر GitHub Actions باستخدام `node --check`، كما يتم تشغيل خادم HTTP محلي واختبار تحميل `index.html` وملفات JavaScript وCSS الأساسية.

للنشر عبر GitHub Pages، اختر الفرع `main` والمجلد `/ (root)` من Settings → Pages.

> لا تضع ملف الموسوعة الكاملة أو أي محتوى مدفوع داخل المستودع العام. المستودع مخصص لواجهة المعاينة ومحتوى العرض العام.
