# منصة الموسوعات الذكية

واجهة عربية RTL لمعاينة موسوعة الذكاء الاصطناعي مع 20 صفحة مجانية، منطقة عرض للنسخة الكاملة، ومساعد محادثة أولي للإجابة عن أسئلة العميل حول المحتوى والسعر والشراء.

## البنية
- `index.html` الواجهة الرئيسية.
- `assets/styles.css` التصميم.
- `assets/app.js` المعاينة والمساعد التفاعلي.
- `assets/config.js` إعدادات المنتج والسعر والعرض.
- `assets/preview/` صفحات المعاينة العشرون.

## تحديث السعر والعرض
عدّل القيم في `assets/config.js`:
- `price`
- `currency`
- `oldPrice`
- `offerTitle`
- `offerText`
- `purchaseUrl`

## النشر
ارفع محتويات هذا المجلد إلى جذر مستودع GitHub، ثم فعّل GitHub Pages من Settings → Pages واختر الفرع `main` والمجلد `/ (root)`.

> لا تضع ملف الموسوعة الكاملة أو أي محتوى مدفوع داخل المستودع العام. النسخة الحالية تحتوي على صفحات المعاينة فقط.
