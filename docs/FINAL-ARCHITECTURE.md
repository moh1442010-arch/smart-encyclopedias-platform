# البنية النهائية لمنصة الموسوعات الذكية

## المنتج
- الموسوعة الكاملة: 250 صفحة
- المعاينة: 20 صفحة
- السعر المحلي: 130,000 جنيه سوداني
- أول 100 نسخة: 117,000 جنيه
- خصم الطلاب: 10% بسعر 117,000 جنيه
- السعر الدولي: 19 USD
- سعر العرض الدولي: 16 USD
- الوكيل الذكي: مشمول مع كل نسخة كاملة

## مسار البيع
1. الزائر يفتح المتجر.
2. مساعد المبيعات يشرح المنتج ويعرض السعر المعتمد.
3. الزائر يرسل طلب الشراء.
4. Backend يستقبل الطلب ويصدر License ID.
5. وكيل المدير يراجع الطلب وحالة الدفع.
6. بعد اعتماد الدفع، ينشأ وصول المشتري.
7. ينشأ Customer Agent مرتبط بالترخيص.
8. يرسل البريد رابط الموسوعة وبيانات الوصول ورابط الوكيل.

## عزل العملاء
كل مشتري له License ID مستقل. لا يسمح لوكيل مشتري بالوصول إلى ترخيص أو بيانات مشتري آخر.

## الأمن
- لا تحفظ مفاتيح API في الواجهة العامة.
- لا تحفظ كلمات المرور في GitHub.
- لا تعرض رابط النسخة الكاملة في HTML العام.
- التحقق من الترخيص يتم في Backend.
- يمكن إلغاء الترخيص وإيقاف وصول العميل.

## توزيع المكونات
- GitHub Pages: واجهة المتجر العامة فقط.
- Backend/Worker: الطلبات والتراخيص والتسليم.
- خدمة القراءة: المحتوى الكامل المحمي.
- خدمة البريد: رسالة التسليم.
- Customer Agent: وكيل العميل المرتبط بالترخيص.
- Sales Manager Agent: إدارة الطلبات والتسليم.

## بوابة الإطلاق
لا يعتبر النظام مكتملًا للبيع الآلي حتى ينجح اختبار كامل ببيانات تجريبية من الطلب إلى التسليم، مع عدم استخدام بيانات دفع حقيقية أثناء الاختبار.
