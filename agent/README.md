# وكيل منصة الموسوعات الذكية

هذه الطبقة تفصل واجهة الوكيل الموجودة في GitHub Pages عن نموذج الذكاء الاصطناعي.

## البنية

- `worker.js` بوابة API تعمل على Cloudflare Workers.
- مفتاح مزود الذكاء الاصطناعي يبقى في Secrets على الخادم ولا يوضع في `config.js` أو المتصفح.
- واجهة الموقع تستدعي `/api/agent` عند ضبط `agentApiUrl`.
- عند غياب البوابة، يحتفظ الموقع بالوكيل المحلي الحالي بدل تعطيل الموقع.

## الإعداد

1. أنشئ Cloudflare Worker.
2. انسخ محتوى `worker.js` إلى العامل.
3. أضف Secret باسم `GEMINI_API_KEY`.
4. انشر العامل.
5. ضع رابط العامل في `assets/config.js` داخل `agentApiUrl`.
6. اختبر أسئلة المعرفة وتنفيذ المهام من الموقع.

## حدود الأمان

- لا تضع مفتاح Gemini داخل GitHub أو JavaScript المرسل للمتصفح.
- العامل لا ينفذ أوامر عامة على الخادم.
- أدوات الوكيل محددة في قائمة مسموحة.
- لا تُرسل بيانات الدفع الحساسة إلى النموذج.

```json
  "context": {

```
