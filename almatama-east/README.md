# موقع المتمة | التاريخ والجغرافيا والمعالم

هذا الموقع مخصص لتوثيق قرية المتمة شرق: التاريخ، الجغرافيا، المعالم، المدارس، الخدمات، الموروث الاجتماعي والأنساب.

## التعديل لاحقاً
- المحتوى الرئيسي: `index.html`
- التصميم: `style.css`
- التفاعل: `script.js`
- يمكن إضافة صور داخل مجلد `images`
- يمكن إضافة صفحات جديدة داخل `almatama-east`
