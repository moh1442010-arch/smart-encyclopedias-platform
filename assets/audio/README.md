# ملفات المعاينة الصوتية والمرئية

يجب وضع ملفات الوسائط النهائية هنا مباشرة، وليس داخل مجلد فرعي أو مجلد يحتوي على مسافة في اسمه.

الأسماء المعتمدة في `preview.html`:

- `intro-ai.mp4` — مقدمة بالذكاء الاصطناعي

بعد رفع الملفات الثلاثة، ستعمل مشغلات الصوت والفيديو في صفحة `preview.html` مباشرة.
